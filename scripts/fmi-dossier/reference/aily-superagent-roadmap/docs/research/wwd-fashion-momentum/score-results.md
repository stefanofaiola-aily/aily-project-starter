## Calculations and interpretation

For each usable signal: **growth = current/reference − 1; raw score = 50 × current/reference; bounded score = min(75, max(60, raw score))**. Average bounded components equally, then round the final display half-up. Missing or zero baselines are excluded. Two components allow a disclosed index; one allows growth only.

The 60–75 presentation bounds flatten both declines and strong growth. A 60 does not mean positive momentum. The score is not percentage growth, AI readiness or a sales forecast. Show actual growth beside the index.

| Brand | EMV raw → bounded | ER raw → bounded | Mean → display |
| --- | ---: | ---: | ---: |
| Coach | 114.1667 → 75.0000 | 165.3846 → 75.0000 | 75.0000 → 75 |
| Fendi | 63.8756 → 63.8756 | 97.7273 → 75.0000 | 69.4378 → 69 |
| Ralph Lauren | 16.3551 → 60.0000 | 115.3846 → 75.0000 | 67.5000 → 68 |
| Burberry | 32.2689 → 60.0000 | 68.7500 → 68.7500 | 64.3750 → 64 |
| Calvin Klein | 24.2972 → 60.0000 | 64.5161 → 64.5161 | 62.2581 → 62 |

Values shown here are formatted for readability; calculations use source inputs without intermediate rounding. Published EMV and rate inputs are already rounded. Source-reported EMV YoY: Burberry −36%, Fendi +28%, Coach +128%, Ralph Lauren −68%, Calvin Klein −52%. Recomputed growth differs slightly because the reports publish rounded inputs and their capture windows are not fully known.
